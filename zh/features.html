Senvarico 功能

为跨境小卖家刻意收窄的功能集。要学的更少、要付的更少、要维护的更少。

Senvarico 是一款面向预算有限、SKU 较少的跨境小卖家的轻量级独立站建站工具。

产品状态：Senvarico 已开放使用，处于 Beta 阶段。本站的事实（价格、上限、支付方式、功能）描述当前 Beta 版本；如有变化，会先在本站更新。

当前范围

托管式店面

在 Senvarico 托管的域名或你自己的域名上运行的在线店铺。没有服务器、更新或安全补丁需要你管理。

小型商品目录

面向大约 10–100 个 SKU 的店铺的商品、变体、图片和库存管理（免费版 20 个，小卖家版 100 个）。

基础订单管理

面向单店、直接面向消费者销售的直观结账和订单列表。不含多仓库或 B2B 流程。

多语言、多币种

店面支持多语言和多币种，适合同时面向欧美多个市场的卖家。

PayPal 和 Stripe

通过 PayPal 和 Stripe 结账。平台交易佣金 0%；支付通道按自身费率收取手续费。

中英文后台

后台同时提供中文和英文界面。

无代码编辑

店面页面和内容通过可视化界面编辑。不需要写主题代码，也没有插件需要维护。

基础 SEO

页面标题、描述、简洁 URL 和服务端渲染的商品页，让店铺可以被搜索引擎读取。

刻意不做的部分

Senvarico 是一个轻量级电商平台。保持轻量意味着对主要服务于大企业的功能说不。以下内容不在产品方向之内：

  • 上千个 SKU 的目录或层级很深的商品结构
  • 多仓库库存、批发或 B2B 分级定价
  • 第三方应用市场或插件生态
  • 自定义服务端代码、自托管或由卖家管理基础设施
  • 多部门权限、复杂审批流程等企业级功能

需要这些能力的卖家更适合功能更全面的平台。参见 Shopify 替代方案总览，了解不同平台适合的卖家规模。

完整功能清单

  • 中文后台
  • 英文后台
  • 零代码建站
  • SaaS 托管，无需自行维护服务器
  • PayPal 收款
  • Stripe 收款
  • 多语言店面
  • 多币种店面
  • 商品管理
  • 基础订单管理
  • 基础页面编辑
  • 基础主题模板
  • 适合 10–100 个 SKU
  • 适合 TikTok / Facebook 广告测款

Senvarico 不是企业级 ERP、大型仓储管理、高级 OMS、POS、Marketplace、大型多门店系统或大型 B2B 平台。常见问题见 常见问题。

定价

免费版 0 元/月（最多 20 个 SKU）；小卖家版 99 元/月（最多 100 个 SKU）；平台交易佣金 0%。
